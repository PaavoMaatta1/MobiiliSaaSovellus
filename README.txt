Google Maps toiminta:

- Hanki API-avain täältä: https://developers.google.com/maps/documentation/android-sdk/get-api-key

- Lisää projektin root kansioon secrets.properties ja local.defaults.properties tiedostot.

secrets.properties tiedostoon lisää: 'MAPS_API_KEY=API-avain'

local.defaults.properties tiedostoon lisää: 'MAPS_API_KEY=DEFAULT_API_KEY'
